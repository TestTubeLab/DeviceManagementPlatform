# 设备管理平台 - 功能清单

> 最后更新: 2025-11-26

---

## 核心功能

### ✅ 已实现

| 功能模块 | 功能点 | 说明 |
|----------|--------|------|
| **设备管理** | 设备自动注册 | Agent 安装后自动注册到平台 |
| | 心跳监控 | 30秒心跳，自动更新在线状态 |
| | 资源监控 | CPU/内存/磁盘使用率 |
| | 设备详情 | 查看设备信息、状态、资源 |
| | 自动部署配置 | 设备上线时自动部署指定项目 |
| | 设备分组 | 给设备打标签便于管理 |
| **项目管理** | 项目创建 | 配置镜像、代码包、启动命令 |
| | 本地镜像支持 | 使用设备预装的 Docker 镜像 |
| | 代码包上传 | 上传 ZIP 格式业务代码 |
| | 一键部署 | 选择设备，一键部署项目 |
| | 批量部署 | 同时部署到多台设备 |
| | 容器配置 | NVIDIA Runtime、Host 网络、特权模式 |
| **任务管理** | 部署任务列表 | 查看所有 ProjectDeployment 任务 |
| | 实时进度 | Agent 上报部署进度 |
| | 任务详情 | 查看任务状态、消息、错误信息 |
| **仪表盘** | 设备统计 | 在线/离线/待部署设备数量 |
| | 状态分布图 | 饼图展示设备状态分布 |
| | 最近任务 | 显示最近部署任务 |
| **用户认证** | 登录/登出 | Token 认证 |
| | 权限控制 | Agent API 无需认证，管理 API 需认证 |

## 删除的功能

以下功能已从平台中移除：

| 功能 | 移除原因 |
|------|----------|
| **镜像仓库** | 用户使用本地预装镜像，不需要上传大镜像到平台 |
| **部署中心** | 已被"项目管理"的部署功能替代 |
| **旧部署任务** | DeploymentTask 已被 ProjectDeployment 替代 |
| **旧更新任务** | UpdateTask 暂时保留后端，前端已移除 |

## 页面入口

### 侧边栏菜单

```
监控仪表盘  →  总览设备和任务状态
设备管理    →  查看设备列表、进入设备详情
项目管理    →  创建项目、上传代码、部署到设备 ⭐
任务管理    →  查看部署任务进度
```

### 操作流程

```
1. 设备安装 Agent  →  设备自动注册上线
2. 项目管理        →  创建项目，配置镜像和代码
3. 项目管理        →  点击"部署"按钮，选择设备
4. 任务管理        →  查看部署进度和结果
```

## 数据模型

### 核心模型

| 模型 | 用途 |
|------|------|
| `Device` | 设备信息、状态、资源使用 |
| `Project` | 项目定义、镜像、代码包、启动配置 |
| `ProjectDeployment` | 项目部署任务、状态、进度 |
| `CodePackage` | 上传的代码包 |
| `ProjectConfig` | 项目配置键值对 |

### 保留但不在前端展示

| 模型 | 说明 |
|------|------|
| `DockerImage` | 原镜像仓库功能，保留兼容性 |
| `DeploymentTask` | 旧部署任务，保留兼容性 |
| `UpdateTask` | 旧更新任务，保留兼容性 |
| `DeviceLog` | 设备日志，待开发 |

## API 端点

### 公开 API (Agent 调用，无需认证)

| 端点 | 方法 | 用途 |
|------|------|------|
| `/api/devices/register/` | POST | 设备注册 |
| `/api/devices/{id}/heartbeat/` | POST | 心跳上报 |
| `/api/devices/` | GET | 设备列表 |
| `/api/devices/{id}/` | GET | 设备详情 |
| `/api/project-deployments/` | GET | 部署任务列表 |
| `/api/project-deployments/{id}/update_progress/` | POST | 更新部署进度 |
| `/api/install.sh` | GET | Agent 安装脚本 |
| `/api/agent-script/` | GET | Agent 脚本下载 |

### 认证 API (需要 Token)

| 端点 | 方法 | 用途 |
|------|------|------|
| `/api/auth/login/` | POST | 用户登录 |
| `/api/auth/logout/` | POST | 用户登出 |
| `/api/projects/` | CRUD | 项目管理 |
| `/api/projects/{id}/deploy/` | POST | 部署到设备 |
| `/api/code-packages/upload/` | POST | 上传代码包 |
